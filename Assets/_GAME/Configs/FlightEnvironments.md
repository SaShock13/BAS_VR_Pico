# Полётные окружения

Общая сцена: `Assets/Scenes/FlightCoreScene.unity`. Здесь находятся XR Origin, инсталлеры, управление, меню и bootstrap. Будущий HUD добавляется сюда.

Окружения: `FlightScene.unity` (учебная площадка) и `FlightScene_Obstacles.unity` (ворота). Они загружаются по одному в режиме Additive. Не добавляйте в них камеры, XR Origin, EventSystem или SceneContext.

## Добавить локацию

1. Создайте сцену с геометрией, коллайдерами и освещением. Можно продублировать существующее окружение.
2. Добавьте один `FlightEnvironmentContext`. Укажите `Player Spawn` (положение корневого объекта XR-рига на полу, без высоты головы) и `Drone Spawn` (положение и направление дрона). Обе точки должны принадлежать этой сцене.
3. Откройте `Assets/_GAME/Configs/FlightEnvironmentCatalog.asset`.
4. Нажмите «Добавить локацию», задайте уникальный постоянный ID, название и описание. Перетащите сцену в поле «Сцена окружения».

Сцена автоматически добавляется в Build Profiles Scene List при редактировании каталога; перед сборкой список также синхронизируется. Меню читает каталог и поддерживает любое количество записей через перелистывание. Удаление записи из каталога убирает локацию из меню, но не удаляет её сцену из проекта или Build Profiles.

Кнопка «В ПОЛЁТ» проверяет дрон и открывает выбор локации. «Начать полёт» повторно проверяет дрон, сохраняет сборку и запускает существующее подтверждение для миссий. Bootstrap дожидается окружения и только потом создаёт дрон. При возврате в сборку выгружаются общая сцена и окружение.

Для просмотра и редактирования уровня можно открыть общую сцену и окружение одновременно. Для запуска из сборки используйте ConstructorScene; запуск FlightCoreScene напрямую использует последнее выбранное окружение либо первое из каталога, без дрона при отсутствии FlightSession.

## Проверки

- `Tools > BAS VR > Flight > Verify Environments And Selection`: структура сцен, ссылки точек старта, список сборки и действия меню.
- Zenject Validate Current Scenes: проверка DI для ConstructorScene и FlightCoreScene.
- Проверка на PICO: выбор обеих локаций, запуск валидированного дрона, пауза и возврат; измерение времени кадра после прогрева. Дополнительных Update, камер или настроек качества фича не добавляет.

`Create Common Flight And Environments` — одноразовая миграция исходной сцены. Для новых локаций повторно запускать её не нужно.
